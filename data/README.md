# Data

The employee dataset (1,452 employees, 39 columns: demographics, job role, department, region, compensation, tenure, overtime, satisfaction scores and an **Attrition** Yes/No label) was provided by the module team for the coursework. It is not redistributed here.

The organisation is a pseudonym ("Pharmeasy Ltd."), and the data contains no real personal information.

**Pipeline:** raw extract → cleaned in R (`Cleaned_employeeSV.xlsx`) → Tableau storyboard and KNIME workflow. To re-run the KNIME workflow with your own copy of the data, point the **Excel Reader** node at the file.
